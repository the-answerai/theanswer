## Executive Summary

This is a **simplified redesign** of the AnswerAgent documentation navigation. The goal: **make it dead simple** for visitors to understand what we do and find what they need.

### Core Principle

**Less is more.** Every visitor should understand AnswerAgent in 30 seconds and find what they need in 2 clicks.

---

## Top Navigation (SIMPLIFIED)

```
[Logo] | How It Works | Pricing | Developers | Blog | [Get Started]
```

That's it. **Five links + one CTA button.**

### Why This Works

1. **Homepage** tells the complete story (no need for "About Us")
2. **How It Works** explains the three pillars in one page
3. **Pricing** is crystal clear (no hidden costs)
4. **Developers** get their own dedicated page
5. **Blog** for content marketing
6. **Get Started** is the single clear action

## Logo API Integration (LogoKit)

**API Endpoint:**
```
https://img.logokit.com/{domain}?token=pk_fr8710fea017bdf10b13fe
```

**Usage:**
- Integration catalog page (grid of logos)
- How It Works page (show integrations)
- Use case pages (show which tools involved)

**React Component:**
```tsx
const IntegrationLogo = ({ domain, alt, size = 'md' }) => {
  const LOGOKIT_TOKEN = 'pk_fr8710fea017bdf10b13fe'
  const sizes = { sm: 24, md: 60, lg: 120 }

  return (
    <img
      src={`https://img.logokit.com/${domain}?token=${LOGOKIT_TOKEN}`}
      alt={alt}
      height={sizes[size]}
      loading="lazy"
      onError={(e) => e.currentTarget.src = `/img/integrations/${domain}.svg`}
    />
  )
}
```
