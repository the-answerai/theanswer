## 1. Official Features (From Anthropic)

### Core Model Improvements
- Enhanced coding & planning — plans more carefully, sustains agentic tasks longer
- **1M Token Context Window** (Beta) — 1,500 pages, 30,000 lines of code, or 1+ hour of video
- **128K Output Token** support
- **Adaptive Thinking** — first Anthropic model with this feature
  - Four effort levels: low, medium, high (default), max
  - Developers control with `/effort` parameter

### New Features
- **Agent Teams**: Multiple AI agents work in parallel, coordinate directly
- **Claude in Excel**: Multi-step changes in one pass, long-running tasks
- **Claude in PowerPoint** (Research Preview): Reads layouts/fonts/templates, preserves design
- **Context Compaction** (Beta): Claude summarizes its own context for longer tasks
- **US-Only Inference**: 1.1x pricing

### Pricing & Availability
- $5/$25 per million input/output tokens (unchanged)
- Premium >200k tokens: $10/$37.50
- Up to 90% savings with prompt caching, 50% with batch (combinable)
- Live on: claude.ai, API (`claude-opus-4-6`), Bedrock, Vertex AI, Microsoft Foundry
- Retirement: not before February 5, 2027
